Безлимитный редактор

Тот же AI, но на его странице: пройди проверку «я не робот», загрузи фото, вставь промпт и жми Generate. Результат: зажми картинку → Сохранить в Фото.

Ключ Hugging Face

Необязательно. Без ключа AI-фото даёт несколько переделок в день. С бесплатным ключом — больше.
1) Зарегайся на huggingface.co (бесплатно)
2) Settings → Access Tokens → Create new token → тип Read
3) Вставь сюда. Ключ хранится только на этом телефоне.
